# 圖片放置說明

把網站要用的圖片放到這個資料夾（`public/images/`），檔名對應如下即可自動顯示。
若尚未放圖，網站會顯示友善的佔位提示（不會破圖）。

| 檔名 | 用途 | 建議尺寸 |
| --- | --- | --- |
| `logo.svg` | 網站 Logo（已附範例，可替換） | 正方形 |
| `hero.jpg` | 首頁主視覺大圖 | 1200 × 900 |
| `about.jpg` | 關於我們區塊圖片 | 800 × 600 |
| `env-1.jpg` ~ `env-6.jpg` | 環境介紹照片牆（6 張） | 800 × 600 |
| `teacher-1.jpg` ~ `teacher-4.jpg` | 師資照片（4 張，正方形最佳） | 400 × 400 |

## 如何換圖

- **最簡單**：用「相同檔名」的新圖片覆蓋上面的檔案，網站不用改任何程式碼。
- **想改檔名或新增**：到 `src/data/siteConfig.ts` 修改對應的 `src` 路徑即可。

> 圖片路徑格式一律為 `images/檔名.jpg`（開頭不用加斜線）。
